# Web 功能地图

各页面的大致功能，侧重不显眼的入口。功能变化时必须同步更新。

- **全局**：⌘K 搜索所有会话的消息，点结果直接定位到那条；右上角通知铃汇总 agent 的主动推送，可「去会话里问」接着追问。
- **侧栏**：在「聊天」和「Trace」两种列表间切换；会话可置顶、归档、按标签筛选；底部依次是设置、一键更新、开发者诊断、主题切换。
- **会话页**：
  - 消息：悬停回复看耗时、token 和缓存命中；压缩和历史整理都可撤回；`ask_user` 以问卷卡片作答。
  - 输入框：`/` 补全指令和 skill；支持拖拽或粘贴附件；执行中按 Esc 停止；✦ 灰字是预测的下一句，Tab 或 → 填入。
  - 工具栏：人设、凭据脱敏开关、上下文占用圆环（点开看构成）、模型与思考强度。
  - 后台任务条：查看任务输出、回复子 agent、终止任务。
- **定时任务**：任务在对话里创建，这里查看运行记录，启停或编辑。
- **设置**：对话偏好（含杂活模型、推送渠道）、人设、标签、服务商与模型（含计费单价）、微信扫码登录、设置备份与导入。
- **Trace**：按轮查看每步模型调用、工具与预测，详情里看实际输入和日志；看板页签汇总用量与费用。
- **开发者诊断**：运行日志、SQL 查询（默认只读，写入前先把关并备份）、服务一键更新。
