## r2 方向与复杂度去向

建议原部署目录 `git pull --ff-only` → `./build.sh` → 正常停止旧运行、exec。保留 target/node_modules 缓存；拒绝未提交改动，不 stash/reset。取消临时 worktree、独立 target 与新增 nix 的方案。

代价已接受为本次草案取舍：pull 后编译失败，磁盘源码是新版而运行程序是旧版；源码不自动回退，人工修复/再构建。失败恢复回到终端，previous 只恢复二进制；数据库若已升级，旧版可能无法打开。

代理首先建议放启动 shell 的 HTTP_PROXY/HTTPS_PROXY/NO_PROXY，让 Git/Cargo/Bun 共用；pull 最多 3 次，不自动改为直连。具体优先级、服务器已有配置和 Bun install 生效仍须核对。
