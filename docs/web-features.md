# Web 功能地图

各页面的大致功能，侧重不显眼的入口。功能变化时必须同步更新。

- **全局**：未登录或登录过期时显示登录页（用户名 dzmfg），登录后回到原地址，30 天内用过就保持登录；⌘K 搜索所有会话的消息，点结果直接定位到那条；右上角通知铃汇总 agent 的主动推送，可「去会话里问」接着追问；开了系统通知的设备同时弹出，点开进入来源会话。
- **侧栏**：在「聊天」和「Trace」两种列表间切换（看子 agent 的 Trace 时切回聊天，回到它的父会话）；会话可置顶、归档、按标签筛选，行首依次显示新回复点、未发送草稿的铅笔，悬停仍可置顶（手机从 ⋯ 菜单置顶），「更早」默认折叠，点击展开；底部依次是设置、一键更新、开发者诊断、主题切换、退出登录。
- **会话页**：
  - 消息：图片点开放大（Trace 里同样）；工具行显示执行耗时；悬停回复看耗时、token 和缓存命中（手机点耗时胶囊展开，点自己的消息显示复制和时间）；压缩和历史整理都可撤回；`ask_user` 以问卷卡片作答。上翻阅读时新输出暂不插入列表，底部按钮变为「有新内容」，回到底部再展开。
  - 输入框：`/` 补全指令和 skill；支持拖拽或粘贴附件（每条最多 10 张图片、4 个文件），整个对话区域均可接收文件，拖入时输入框显示落点提示，待发送附件横向排列，可查看名称、大小并移除，图片点开放大；未发送的文字、附件和引用按会话保留到刷新前；执行中按 Esc 停止；✦ 灰字是预测的下一句，Tab 或 → 填入。
  - 工具栏：人设、凭据脱敏开关、上下文占用圆环（点开看构成）、模型与思考强度；新会话页发送前同样可选人设、模型和脱敏开关。
  - 后台任务条：查看任务输出、回复子 agent、终止任务。
- **定时任务**：任务在对话里创建，这里查看运行记录，启停或编辑。
- **设置**：手机先列分组目录，点进分类，返回回到目录；对话偏好（含杂活模型、推送渠道、本设备系统通知开关：iPhone 须先添加到主屏幕并从主屏幕打开）、人设、标签、服务商与模型（含计费单价）、命令环境变量（值只显示两头、发给模型前脱敏）、微信扫码登录、设置备份与导入、账号（改登录密码，其他设备随之退出；忘记密码在服务器上运行 `micnext --set-password`）。
- **Trace**：按轮查看每步模型调用、工具与预测，最新一轮执行中每 5 秒自动更新，详情里看实际输入和日志；看板页签汇总用量与费用。
- **开发者诊断**：运行日志、SQL 查询（默认只读，写入前先把关并备份）、服务一键更新。
