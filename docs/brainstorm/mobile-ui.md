# 移动端配置与交互优化（B1）

状态：已选定 A + B（设置目录），C 不做。2026-11-10。

## 决定

- 不单独做一套移动端页面，同一组件按宽度与触屏（`pointer-coarse`）调整排版和触摸目标。
- 优先对话页与会话列表：回复下的复制与耗时胶囊在触屏常显，点开看完整统计；点自己的消息显示复制与时间；输入栏窄屏分两行：附件、输入、发送同一行，人设图标、脱敏开关、上下文、模型在下，按钮加大，留出底部安全区；标题栏窄屏只留标题一行，Trace 移到右侧；会话行加高，置顶改从 ⋯ 菜单。
- 设置：手机先显示分组目录，分类走 `/settings/<tab>`，浏览器返回回到目录。
- 服务商弹窗：连接字段纵排、错误完整换行、输入 16px；全屏表单与人设、环境变量表单待真机反馈再定。

## 范围与依据

检查当前工作区的 Svelte 页面与共享控件，覆盖设置、服务商编辑、聊天输入、人设/模型选择和侧栏。保留现有明暗主题与视觉语言。本轮未获得可自动控制的浏览器页面，以下为代码审查结论；软键盘、实际触摸和页面观感仍需真机确认。工作区已有的新会话配置等改动属于其他进行中工作，本方案不覆盖其业务语义。

## 当前问题

| 场景 | 证据 | 影响 |
|---|---|---|
| 手机寻找环境变量、微信、备份 | `settings/SettingsView.svelte` 在窄屏将七个分类放在横向滚动导航中 | 后面的分类首屏不可见，需要主动探索 |
| 编辑服务商名称和类型 | `settings/EndpointDialog.svelte` 连接区域固定 `1fr auto` 两列，类型选择宽 `w-40`；弹窗两侧各有 padding | 名称输入空间不足；已有模型区断点适配没有覆盖连接区 |
| 查看连接失败原因 | 同文件测试结果使用 `truncate`，完整内容只放 `title` | 触屏难以读取完整错误，妨碍配置排错 |
| 长表单与软键盘 | 共享弹窗居中定位，服务商弹窗上限 `85vh`；全局仅 `height:100%` | 键盘打开后的可见区、保存按钮可达性需真机验证，不能仅凭 vh 宣称已适配 |
| 点击复制、停止、附件和模型行操作 | `ReplyView.svelte` 回复操作栏默认透明，仅 hover/focus 显示；共享 Button 存在 24/32px 规格，Composer 主按钮 36px | 触摸入口发现困难、小目标容易点偏 |
| 编辑配置输入框 | 共享 Input 默认移动端 `text-base`，但服务商模型 ID、数字框、key 等局部覆盖 `text-xs` | 手机可读性变差；iOS 聚焦行为需真机验收 |
| 刘海与底部手势区 | `index.html` 设置 `viewport-fit=cover`，web 中未见 safe-area inset 消费 | 横屏与底部操作区存在遮挡风险，需要真机复现 |

## 候选与取舍

### A：保留结构，修正触屏适配（推荐首批）

- 保留分类横栏，但提供完整分类入口和当前分类反馈；调整为足够高的触摸行。
- 服务商连接字段在手机纵排；字段名称独立展示，不只用 placeholder；错误完整换行。
- 长编辑表单在手机使用接近全屏的布局，标题和底部操作固定，正文独立滚动；桌面保留现有弹窗。先覆盖服务商、人设、环境变量，再按实际重复收敛共同样式。
- 手机编辑字段保持清晰字号，数字字段使用合适键盘；高频操作有效触摸区目标 44px，不把所有桌面控件一律放大。
- 触屏下显式提供回复复制入口；统计详情采用可点入口，避免把整条统计常驻挤进正文。
- 检查聊天工具栏的换行和长模型名；保留人设、模型、思考强度的现有含义。
- 补齐页面安全区，验证键盘出现、收起和旋转后的输入及滚动行为。

收益：变动集中，沿用现有页面与状态。代价：分类仍以横栏为主，导航信息层级改善有限。

### B：设置改成手机目录 → 分类详情

手机先显示七个配置分类列表，进入后显示单类内容，提供明确返回；桌面保留侧边导航。编辑长表单同 A。

收益：所有分类可发现，适合后续配置项增长。代价：多一次进入操作；需明确浏览器返回、分类定位、从 Trace 跳到计费设置的行为。这部分涉及公开导航契约时先写 B2，批准后实施。

### C：合并聊天配置为单一底部面板

手机聊天只显示当前配置摘要，点击展开人设、模型、思考强度等设置。

收益：输入区更简洁。代价：频繁切模型增加一步，且脱敏等敏感开关需要保持明确状态。暂不推荐在首批同时改动。

## 建议顺序

1. A 中的表单排版、完整错误、触摸入口、字号、安全区。
2. 在 A 的分类入口改良与 B 的目录导航中选定一个方向。
3. 根据真机结果决定是否需要 C，不提前增加新的配置状态或后台机制。

## 验收

- 320、390、430px 宽度：设置与服务商表单无页面级横向溢出；长模型 ID、URL 和错误能读完整。
- 服务商添加/测试/编辑/保存、人设编辑、环境变量编辑均可单手完成主要点击；取消和未保存提示维持原有语义。
- 真机键盘打开后输入可见、能滚到最后字段、保存可达；收起键盘后无多余空白或跳位。
- 新会话与已有会话的人设/模型操作可用；复制入口无需 hover；发送与停止不误触。
- 深浅主题、横屏、安全区和桌面回归。
- 实现后运行 `cargo fmt`、`cargo clippy -- -D warnings`、`web/` 下 `bun run check`；页面观感与真实环境由 human 验收。
