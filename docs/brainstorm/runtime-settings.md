# 运行期设置：人设、提示词分块与配置边界（2026-10-08）

状态：B1 已收敛；阶段一已实现（2026-10-08），B2 见 [`blueprints/runtime-settings.md`](../blueprints/runtime-settings.md)（与 storage-and-models §二 合并）。

核心划分：**设置页管长期偏好，会话保存下一轮选择，run 保存当轮事实。**

## 一、配置边界

- `config.toml` 只放**启动必需、或不能让网页改的**：数据目录、监听地址、访问 token（以及将来的日志级别）。
- 其余用户可调项进 SQLite，经 Web 设置页修改，下一轮 run 生效，不重启。

| 项 | 去向 | 理由 |
|---|---|---|
| `core.data_dir` | 留 | 找到库之前就要知道 |
| `gateway.listen`、`gateway.token` | 留 | 网页起来之前就要知道；能从网页改等于能自己改门锁 |
| `core.max_turns` | 库 | Agent 行为参数 |
| `gateway.workdir` | 库 | 「新会话默认工作目录」，改了不搬已有会话 |
| `[models]` | 库 | 已定，见 storage-and-models §二 |
| `core.owner` | 本次不动 | 它是消息归属身份，不是昵称；改它会切断历史归属。只想改称呼就写进通用偏好 |

## 二、system prompt 分块

固定顺序：**系统 → 人设 → 通用偏好**，之后才是工作目录、工具提示、摘要。

- **系统**：二进制常量，不入库、不可改，设置页只读展示。它解释框架协议，必须与代码同版本。
- **人设**：只有「名字 + 提示词」，不绑模型、工作目录、工具权限。3 个内置人设，只读、不可删，只能「复制并编辑」；以源码文件为准，每次启动同步覆盖（2026-10-08 修订，原为建库一次性写入），不做恢复默认。
- **通用偏好**：一段全局文本，对所有人设生效（语言、回复长短、关于我）。

## 三、会话选择与 run 事实

- **会话保存下一轮选择**（人设，以后加模型），与 run 分开存。「下一轮想用什么」和「上一轮实际用了什么」是两件事，不是重复真相；从 run 反推会让切换未发送、插话、失败、刷新都需要特殊规则。
- 新会话取默认值；改全局默认不影响已有会话。
- 输入框旁显示当前选择；执行中切换显示「下一轮生效」，插话沿用本轮。
- **run 开始时定下全部设置**：人设、通用偏好、模型、轮数上限一次读取，执行中不变。
- run 记人设 id + 当时的名字与原文，以及通用偏好原文；模型已由 `model_call` 记录。界面默认只显示本轮人设与模型，展开「本轮设置」看详情。

## 四、删除人设

- 内置不可删；正被设为全局默认或渠道使用的先换掉才能删；其余可删，历史快照保留。
- 会话仍选着已删除（或内置下线）的人设：提示「原人设已删除」，下一轮自动改用默认人设并写回会话（2026-10-08 修订，原为要求重选）。

## 五、设置页

| 区域 | 内容 |
|---|---|
| 对话偏好 | 默认人设、通用偏好、新会话默认工作目录、轮数上限 |
| 人设 | 内置与自建人设 |
| 模型 | 模型条目、连接参数、密钥、默认模型 |
