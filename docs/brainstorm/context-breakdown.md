# B1：上下文构成

**状态：方向已定（2026-10-16），进 [B2](../blueprints/archive/context-breakdown.md)。不是实现授权。**

human 决定：方格图，要做得好看；工具调用与结果并入「对话」，只在图例里注明其中占比，不做逐条下钻；没有上游总量时不显示构成。

聊天页的上下文占用圆圈（`ContextMeter`）点开后，展示当前上下文由哪些部分组成、各占多少，以及离自动压缩还有多远。参照 Claude Code `/context`，但用 Web 的方式画，不做饼图。

## 一、现有事实

- 总量已有：`occupancy.used_tokens` = 当前有效窗口下最近一次成功对话调用的上游 `input + output`（[chat-run-stats §二](../blueprints/archive/chat-run-stats.md#二上下文占用)），与压缩判定同口径。
- 上游只给总数，不给分项。分项只能靠估算。
- 请求不落盘，但 `request::build` 是纯组装：同一会话的当前窗口、设置、工具、渠道提示重新组装一次，得到的就是「下一次要发出去的请求」。它约等于上次的 input 加上次的 output（output 已成为窗口里的回复）。trace 重建输入走的也是这个函数。
- 请求由三部分组成：`system`（三块）、`messages`、`tools`（工具 schema）。另有 `images`。

## 二、分类

按用户能理解、能采取行动的粒度分，不照搬内部结构。

| 分类 | 来源 | 用户能做什么 |
|---|---|---|
| 框架规则 | `instructions` 块（system.md + 消息头说明） | 不可改，基线 |
| 人设与偏好 | `persona` 块 | 精简人设 |
| 工具 | 工具 schema + 各工具 `prompt_hint` | 以后可关工具 |
| 运行环境 | 工作目录、渠道提示 | 基线 |
| 压缩摘要 | 摘要 + 压缩时的文件快照 | 撤回或重新压缩 |
| 对话 | 用户输入、助手正文、推理回传 | `/compact`、`/clear` |
| 工具结果 | `ToolResult` + 回复里的 `ToolCall` 参数 | 同上；通常是大头，单列 |
| 图片 | `images` | 同上 |
| 剩余空间 | 窗口 − 已用，分成两段：到压缩阈值前、阈值之后 | — |

Claude Code 的 Skills、MCP、自定义 agent 我们没有，不列；以后有了再加一行。「对话」与「工具结果」是否拆开，以及是否再拆出「推理」，见 §四-2。

## 三、估算方法

1. 重新组装当前请求，逐部分估 token：文本按字符估（CJK 约 1 字 1 token，其余约 4 字符 1 token），工具 schema 按序列化后的 JSON 估，图片按固定单价估。
2. 各部分估值之和为 `E`，上游实际总量为 `U`，每部分乘以 `U / E`，合计与圆圈上的数字严格一致。
3. 没有 `U`（`/clear` 或压缩后尚未调用、会话未选模型）：见 §四-3。

不引入 tokenizer 依赖：按比例分配后，估算误差只影响各项之间的比例，不影响总量；各家模型分词也不同，精确分词并不能带来实际收益。

误差来源记在这里，不在页面上展开：组装时的设置可能在上次调用后被改过（人设、工具开关），此时分项是按「现在的配置」分的。偏差可接受，因为用户看构成正是为了决定下一步怎么改。

## 四、待 human 定

1. **展示形式**（推荐 A）
   - A. 方格图：20×10 格，每格 0.5% 窗口，按分类着色；压缩阈值之后的格子用斜纹，与 Claude Code 同思路。右侧列图例：名称、token 数、占比。悬停图例高亮对应格子，悬停格子高亮对应图例。
   - B. 单条横向堆叠条 + 阈值刻度线，下方列表。更省地方，但小项（几百 token）在条上看不见。
2. **分类粒度**（推荐 B）
   - A. 按上表 8 类。
   - B. 在 A 基础上，点开「工具结果」「对话」时列出占用最大的几条（工具名 + 摘要 + token），点击跳到该消息。能直接回答「是什么把上下文撑满了」。
3. **没有上游总量时**（推荐 A）
   - A. 照样显示构成，总数标「估算」。刚 `/clear` 后能看到基线占用（框架规则 + 人设 + 工具）。
   - B. 不显示构成，提示「下一次回复后可查看」。
4. **入口**：点圆圈弹出浮层（宽屏锚定圆圈，窄屏底部弹出）。计算放在点开时按需请求，不随每条回复刷新。

- Web：`ContextMeter` 变为可点击；新增浮层组件。
- 不改 schema，不落盘任何估算结果。
