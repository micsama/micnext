# 能力与边界

限额数值以各 crate 的 `limits.rs` 为准。

| 能力 | 当前行为与边界 |
|---|---|
| 会话 | Web 可建多个会话；微信进入该账号固定的私聊会话，Web 内只读。同一会话同时一个 run，不同会话并行；执行中的新输入在下一个模型调用边界并入当前 run。断线按消息 id 回放，流式草稿随重连恢复。归档会话不再执行。 |
| 输入 | 文字、图片（每条 10 张）、文件（每条 4 个）；`/name` 点名 skill。`ask_user` 发问后本轮结束，下一条消息即回答。 |
| 上下文 | 占用达设置的触发比例时自动压缩（摘要点名仍需的文件与 skill，压缩后重载 skill），可手动 `/compact`、可撤回；空闲超阈值（`gpt-` 3 小时，其余 24 小时）后先整理：过半压缩，否则把旧工具输出换成占位。`/clear` 清模型上下文、保留聊天记录。 |
| 工具 | 文件读写搜索、`bash`（可后台、可按输出匹配通知）、`web_fetch`、`web_search`（取第一个提供搜索的服务商）、`send_file`。工作目录以会话为准；命令环境变量在设置里配，发给模型前按值脱敏。无 MCP 客户端。 |
| 后台任务 | 后台 `bash` 与子 agent 都是 job；输出只留最近一部分；管理范围为调用会话及其后代。定时任务会话不能起后台 `bash`。 |
| 子 agent | 在独立子会话执行，工具不超出父会话；结束后结果交付父会话，可追问、可停止；轮数与时长有上限，交付内容会截断。 |
| 定时任务 | 5 段 cron 或一次性时刻，按服务器本地时区；最短间隔 10 分钟，单次 run 30 分钟超时。每个任务有独立会话，工作目录与模型拷自建任务的会话，之后可单独改。可立即执行一次（不动计划）。上次未结束则跳过，停机错过只记录不补跑，连续失败 3 次自动暂停。在对话里建和改，`schedule` 工具不能指定模型。 |
| 推送 | `push` 进 Web 通知中心，并按默认或指定渠道发 IM（目前只有微信）；框架通知用于定时任务失败、错过等。系统通知（Web Push）只推一次、不重试、不同步已读。指定 IM 不可用时 `push` 报错；微信常拒收主动推送。 |
| 微信 | 扫码登录；入站支持文字、图片、文件、视频、引用，不支持的类型转占位并回复说明；出站分段发送，`ask_user` 转编号文字，回复中显示「正在输入」。投递不重试，结果未知记为可能未送达，断线积压不补发。 |
| 模型 | OpenAI 与 ChatGPT 订阅走 Responses，DeepSeek、Ollama 与兼容服务走 Chat Completions；模型可配计费单价；会话可单独选模型与思考强度；一次调用最多尝试 3 次。杂活模型单独选，用于标题、标签、预测、SQL 把关。 |
| 人设与 skill | 内置加自建人设，按会话选；定时任务会话不带人设。磁盘 skill 在 `<data_dir>/skills/<name>/SKILL.md`（frontmatter 的 `name` 与目录名一致，`description` 必填、不超过 1024 字），内置 skill 随二进制发布。安装即放入该目录，不用重启：每轮开始按磁盘现状生成 skill 目录，已有会话下一条消息即可用；输入 `/` 时重新列出，格式不对的显示「不可用」及原因。 |
| 凭据脱敏 | 发给模型前精确替换应用持有的秘密，并按正则遮住明显凭据（正则可按会话关闭）；编码、拆分后的秘密和图片内容不在范围内。本地原文不动。 |
| 设置与账号 | 用户可调项存 SQLite 经 Web 改，`config.toml` 只放启动项。备份导出加密文件，含服务商、模型、人设、偏好、微信账号，不含聊天数据、登录和系统通知订阅。单用户登录制。 |
| 观测 | Trace 按轮看模型调用、工具与预测，可重建实际请求；看板汇总用量、费用与耗时。日志独立成库。SQL 每次一条，默认只读，写入先经杂活模型把关并备份，凭据列读出为 NULL。一键更新在部署仓库 fetch、构建、重启。 |
