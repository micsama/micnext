# B1：Trace AI 概览卡片

状态：选定 2，已实现，human 验收通过，CLOSED（2026-10-19）。只改前端，读取契约不变，未出 B2。

## 现状

AI 概览的「输出摘要」直接取列表 preview，以纯文本最多显示三行，整段点击切到详情。它是原文节选，并非摘要；Markdown 结构丢失，还与详情里的正文重复。详情已按推理、正文、工具调用渲染卡片，长卡片默认正文高度 168px。关联与调用细节目前都是默认展开的分区。

## 候选与取舍

1. 保留详情页签：概览仅放正文预览卡，详情承载全部输出块。改动小，但正文仍需跨页重复，读者要判断何时切换。
2. 合并输出到概览（建议）：概览直接复用完整输出块的卡片渲染，移除 AI 调用的详情页签。正文、过程说明、推理、工具参数按原始顺序显示；长卡片原地展开。输入和日志仍独立。概览变长，通过默认折叠推理与次要信息控制长度。

不对截断后的 preview 渲染 Markdown，避免代码块、列表或链接截断后失真。不另生成摘要，也不新增摘要存储。完整输出沿用现有详情读取，按选中调用加载。

## 建议的卡片规则

- 顺序：异常提示 → 耗时/用量 → 输出卡片 → 关联卡片 → 调用细节卡片。
- 输出卡片不再套一层「输出摘要」容器；沿用正文、过程说明、推理、工具名等准确标题与 Markdown/JSON 渲染、复制。
- 正文默认预览高度从 168px 提到约 280px（约 12 行），窄或矮面板上限随可用高度收缩；短内容自然高度，长内容原地「展开全部 / 收起」。具体尺寸交页面验收微调。
- 推理默认收起到标题，展示字数或加密状态；正文优先可读。工具参数保留有界预览。
- 关联采用中性卡片，默认展开，内部继续用紧凑可点击行，保留来源输入、工具批次、所属轮次跳转；每行不再嵌套卡片。
- 调用细节采用中性折叠卡片，默认只露标题；展开显示结束原因、输出速度、起止时间、缓存写入、编号。异常与主要指标仍在顶部，不藏入折叠区。
- 卡片统一边框、圆角、标题间距；内容裁高与整卡收起是不同交互，不强行共用同一开关语义。

## 边界与验收

本轮聚焦 AI 调用。压缩与标题旁路是否同步合并页签，在方向确认时一并定下，避免误删它们的已有内容。无输出及失败调用不显示空输出卡；重试各次状态、耗时和用量继续保留。

方向确定后再实施；若涉及公开组件签名或读取接口变更，先补 B2。自动验收覆盖 Web check/build 及项目要求的 Rust fmt/Clippy；长 Markdown、工具调用、加密推理、失败重试、关联跳转与窄屏观感由 human 验收。
