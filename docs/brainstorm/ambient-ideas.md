# B1：低存在感的 LLM 应用想法

**状态：想法收集（2026-10-27），不急着做。** 不限于 micnext 本身，也包括电脑、手机和桌面硬件。

## 共同标准

- 输入是自然产生的：截图、命令报错、邮件、手机状态变化，不需要人专门操作。
- 输出只在值得时出现；平时感觉不到，需要时已经准备好。
- LLM 只用来理解没有结构的内容，规则能做的交给规则。先用便宜的分类判断「重要 / 攒着 / 丢掉」，值得的才交给大模型或推送。

## micnext 内

- **滚动条重点刻度**：用意外度试验（[surprisal](surprisal.md)）找出重点分句，只在长回复的滚动条上画细刻度，正文不着色。空闲时用 WebGPU 在后台算，结果缓存。
- **似曾相识**：新会话的第一条消息和旧会话主题相近时，输入框下方显示一行淡色链接。生成标题时顺便用小向量模型算向量，服务器 CPU 就能跑。
- **自动打标签**：生成标题时从已有标签里挑一个，以灰色的「建议」状态显示，点一下才算确认。
- **原地打转提示**：一次运行里同一命令连续失败、反复读同一个文件时，在 Trace 上标出来。规则确定，不需要模型。
- **后台完成时标签页提示**：标签页标题或图标加一个点，切回来就消失；先确认侧栏状态点是否已经覆盖。

## 电脑

- **截图收件箱**：监听截图目录，用本地 OCR（Vision 框架）加小模型重命名、分类（报错 / 待办 / 灵感 / 可删），每周推送一次概况。
- **终端报错提示**：nushell 钩子在命令非零退出时，让本地小模型读最后几十行输出，在下一行用暗色给出一句可能的原因。
- **电脑体检**：定时检查磁盘、`brew outdated`、大缓存、陈旧的分支和 stash；没事不说话，有值得处理的才推送。
- **一句话日报**：本地记录活跃窗口和 OCR，每晚压缩成三句话存起来，不推送，供以后检索「那个报错在哪看到的」。只存摘要，不存录屏。

## 输入法

拼音转汉字本质上是在上下文条件下猜下一个词，对延迟和隐私要求高，只能用本地模型（MLX 或 llama.cpp，0.5B 到 1B），不适合云端分类接口。

- 按上下文（已经打出的字、正在回复的消息）重排候选。
- 同音错字检查：意外度高、而同音字概率高的位置，加淡下划线，不改字。可以先做成独立小工具，复用意外度试验的代码。
- 灰字续写，按 Tab 接受。
- 用自己的聊天记录做本地 LoRA，学会个人用词。
- 可以借助鼠须管（Rime）的 librime-lua 插件调用本机打分服务，不用从零写输入法。动手前先查有没有现成的 Rime + LLM 插件。

## 手机（快捷指令当手脚，服务器上的 agent 做判断）

快捷指令能在到达或离开某地、连接 CarPlay、专注模式切换、碰 NFC 贴纸、电量变化、定时等条件下自动触发，用「获取 URL 内容」请求服务器，再把返回的文字念出来或显示成通知。

- **专注模式同步**（最推荐）：切到睡眠或工作时告诉服务器，不紧急的推送先攒着，结束后合成一条再发。和现有的推送、定时任务衔接。
- **CarPlay 简报**：上车后由 Siri 念出后台任务状态和今天剩下的事。
- **床头 NFC 贴纸**：睡前碰一下，整理当天没跑完的任务，选出明早要先做的一件事。
- **每晚收集截图**：定时把当天的截图传到服务器，分类后把像待办的转成提醒。
- **订阅审计**：读收据和扣款邮件，每月推一次「还在扣费但很久没用」的项目。

缺口：micnext 还没有接收外部事件的接口。直接调用发消息的接口，每个事件都会变成会话里的一条消息。要做到「事件进来、分完类、再决定推不推」，得新增 HTTP 接口，需要先写 B2。

## 桌面硬件

- **墨水屏看板**：ESP32 驱动，只显示一两行：今天最重要的事、后台任务状态、明早第一个日程。内容由 LLM 每小时挑一次。
- **台灯当通知**：长任务完成时变暖色，出错时变红。

## 分类模型

Jev（TypeSafe AI，2026-09 发布）是只做分类的云端模型，返回带概率的类别。厂商称单次 70 到 500 毫秒，准确率接近前沿大模型，成本很低，均未经独立测评。适合做事件分流（重要 / 攒着 / 丢掉），不适合输入法这类每次按键都要响应的场景。

## agent 在服务器上起的服务怎么访问

不在 micnext 里做端口映射：网关子路径转发会让 Vite、Jupyter 这类用绝对路径和 WebSocket 的服务出错，还会把网关变成任意端口的入口。网络层交给 Tailscale，服务器、Mac、iPhone 互通，直接打开 `http://<服务器名>:<端口>`。

- 人设或记忆里写规则：起服务时监听 Tailscale 地址或 `0.0.0.0`，完成后回复可点开的链接。
- 临时开发服务用 bash 后台任务（`timeout_ms: 0`）；它归 micnext 管，重启时进程组会被杀掉。要长期运行的服务让 agent 写成 systemd user unit 或 docker compose。
- 以后常要找「agent 起过哪些服务」时，再考虑在侧栏列出正在运行的后台任务。
