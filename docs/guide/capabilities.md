# 能力地图

本文按用户目标列出 micnext 能做什么，以及行为与边界。网页上的入口见 SKILL.md 正文里的「Web 功能地图」，源码入口见 `code-map.md` 的同名小节，限额数值以各 crate 的 `limits.rs` 为准。

## 对话与会话

- **用户目标**：和 agent 多轮对话，随时接着聊，管理大量历史会话。
- **当前能力**
  - Web 和微信各有自己的会话：
    - Web 会话可以新建多个，也可以在里面发消息。
    - 微信消息进入该账号固定的私聊会话。Web 能查看这个会话，但不能在里面发言（只读）。
  - 输入可以带文字、图片（每条最多 10 张）和文件（每条最多 4 个）。
  - 回复以流式显示。断线重连后，从稳定游标（消息 id）接着回放，正在生成的草稿一起恢复。
  - 会话可以置顶、归档、打标签、全局搜索。标题由杂活模型自动生成，也可以手动要求重新生成。
  - 执行中可以停止（`/stop` 或 Esc）。中断后能接续的 run 可以接续。
  - 执行中再发的输入，会在下一个模型调用边界并入当前 run，不会另开一个 run。
  - `ask_user`：agent 用问卷卡片向用户提问，本轮随即结束，用户的下一条消息就是回答。
  - 输入预测：对话正常结束后，杂活模型猜一句用户的下一句，用灰字显示。只在 Web 上有。
- **边界**
  - 同一会话同时只有一个 run，不同会话之间并行。
  - 归档后的会话不再执行。
  - 子 agent 会话和定时任务会话不在普通会话列表里。

## 上下文管理

- **用户目标**：长会话不爆上下文，并且知道上下文里装了什么。
- **当前能力**
  - **自动压缩**：每步工具结果落盘后检查，上下文占用达到触发比例（可在设置里调）时，先生成摘要，再继续执行。手动压缩用 `/compact [文字]`。压缩可以撤回。
  - 压缩时，摘要会点名仍需要的文件和 skill。压缩后，这些 skill 会被重新加载。
  - **空闲整理**：会话空闲超过阈值后（`gpt-` 模型 3 小时，其余 24 小时），下次执行前先整理：占用过半就直接压缩，否则把旧的工具输出换成占位，这一步不调用模型。
  - `/clear` 清空模型上下文，聊天记录保留。
- **边界**：用量估算以上游返回的 token 为准，只在压缩前裁剪历史时用字数粗估。

## 工具与后台任务

- **用户目标**：让 agent 在服务器上真正干活，长任务不卡对话。
- **当前能力**
  - 文件工具：`read`、`write`、`edit`、`glob`、`grep`。
  - 命令执行：`bash`，可以设超时。
    - 加 `background` 时转为后台任务，立即返回 job id。
    - 加 `notify_pattern` 后，输出一旦匹配就通知会话。
    - 命令里的 Python 使用数据目录下共享的 uv venv。
  - 网络：
    - `web_fetch` 抓取网页。
    - `web_search` 通过服务商联网搜索，取第一个提供搜索的服务商。
  - 任务管理：`jobs`、`job_output`、`job_stop`。管理范围是调用会话及它的后代。Web 上有后台任务条，可以看输出、终止任务。
  - `send_file`：把文件快照交给用户，在 Web 上显示为文件卡片，在微信里按图片或文件发送。
  - 命令环境变量：在设置里配置，执行时注入；发给模型前，按精确值脱敏。
- **边界**
  - 后台任务的输出只保留最近一部分。
  - 定时任务会话里不能用后台 `bash`。
  - 文件工具和命令以会话的工作目录为准。
  - 没有 MCP 客户端。接入方向见 `docs/brainstorm/local-browser-mcp.md`。

## 子 agent

- **用户目标**：把独立的子任务派出去并行做，回头拿结果。
- **当前能力**
  - `agent` 工具：派出子 agent，或给已有子 agent 追问。
  - 子 agent 在自己的子会话里执行，可用的工具不超出父会话。
  - 子 agent 结束后，结果以交付消息回到父会话。
  - 在 Trace 里能看到子 agent 的完整执行过程。
- **边界**：子 agent 的轮数和时长有上限（见 `crates/mic-core/src/limits.rs` 的 `AGENT_*`），交付内容会被截断。

## 定时任务

- **用户目标**：让 agent 按时自动做事，有发现时主动告诉我。
- **当前能力**
  - **创建**：在对话里说就行，由 `schedule` 工具完成。规则是 5 段 cron，或者一次性的 `YYYY-MM-DD HH:MM`，按服务器本地时区计算。
  - **任务会话**：每个任务有自己的会话。工作目录、模型和思考强度从建任务的会话复制过来。之后可以在任务会话里单独改模型，也可以直接对话追问。
  - **执行**：到点后以触发指令开一个 run。
    - 上一个 run 还没结束时，这次触发跳过。
    - 停机期间错过的触发只记录，不补跑。
    - 连续失败 3 次后自动暂停。
  - **定时任务页**：查看运行记录、用量和费用，可以启停或编辑。不能在这里新建任务。
- **边界**
  - 最短间隔 10 分钟，单次 run 30 分钟超时。
  - `schedule` 工具不能指定模型，只能先切好当前会话的模型再建，或者建完去任务会话里改。
  - 任务会话不带人设。

## 推送与通知

- **用户目标**：agent 有事时主动找我，手机上也能收到。
- **当前能力**
  - `push` 工具：带标题和正文，可以附带文件。
    - 每条推送都进 Web 通知中心（右上角的铃）。
    - 同时按「默认推送渠道」或调用时指定的渠道发给 IM（目前只有微信）。
  - **框架通知**：定时任务失败、错过触发等情况，由框架自动推送。
  - **系统通知（Web Push）**：设备开启后，新推送同时弹出系统通知，只推一次，不重试。
- **边界**
  - 指定的 IM 不可用时，`push` 直接报错。框架通知仍会落库，并记下原因。
  - 微信经常拒收主动推送（见 `docs/brainstorm/push-fallback.md`）。
  - 系统通知不做已读同步。

## 渠道：微信

- **用户目标**：不开网页，也能在微信里和 agent 对话。
- **当前能力**
  - 入站：支持文字、图片、文件、视频和引用。不支持的类型转成占位，并回复说明。
  - 出站：回复分段发送；图片和文件按微信能显示的方式发出；`ask_user` 转成编号文字。
  - 回复过程中显示「正在输入」。
- **边界**
  - 投递不重试。结果未知时记为可能未送达。
  - 断线期间积压的消息不补发。

## 模型、人设与 skill

- **用户目标**：自由切换模型和行为风格，扩展 agent 的专长。
- **当前能力**
  - **服务商与模型**：
    - OpenAI 和 ChatGPT 订阅走 Responses。
    - DeepSeek、Ollama 和通用兼容服务走 Chat Completions。
    - 每个模型可以配置计费单价。
    - 有一个默认模型；每个会话可以单独选模型和思考强度。
  - **杂活模型**：用于标题、标签、输入预测、SQL 把关这类旁路用途，单独选择。
  - **人设**：内置人设加用户自建人设，每个会话可以单独选。
  - **Skill**：磁盘 skill 放在 `<data_dir>/skills/<name>/SKILL.md`，内置 skill 随二进制发布（即本指南）。
    - 模型用 `skill` 工具加载，用户用 `/name` 点名加载。
  - **凭据脱敏**：发给模型前，精确替换应用持有的秘密，并按正则遮住明显的凭据。正则这一步可以按会话关闭。
- **边界**
  - 编码、拆分后的秘密，以及图片里的秘密，都不在脱敏范围内。
  - 模型调用失败会自动重试，一次调用最多尝试 3 次。

## 设置、备份与账号

- **用户目标**：在网页上管理所有可调项，换机器时能迁移。
- **当前能力**
  - 用户可调项都存在 SQLite 里，通过 Web 修改。`config.toml` 只放启动项。
  - 设置备份导出为加密文件，内容包括服务商、模型、人设、偏好和微信账号。不包括聊天数据，也不包括登录和系统通知订阅。
  - 登录制，单一密码；登录、改密与找回见「Web 功能地图」。
- **边界**：只有单用户，没有多账号。

## 观测与诊断

- **用户目标**：知道 agent 做了什么、花了多少、哪里出了错。
- **当前能力**
  - **Trace**：按轮查看每次模型调用、工具执行和预测，能重建实际发出的请求和系统提示。
  - **看板**：汇总用量、费用和耗时。
  - **开发者诊断**：
    - 运行日志（实时，也能看历史）。
    - SQL 查询。默认只读；写入前先由杂活模型把关，并自动备份。
    - 一键更新：在部署仓库里 fetch、构建、重启。
- **边界**
  - 日志存在独立数据库里，与业务数据分开。
  - SQL 每次只执行一条语句，有行数和超时上限，凭据列读出来是 NULL。
