# B2：模型收藏

状态：2026-10-27 human 批准；实现完成，本地检查通过，待 human 验收。

## 行为

- **设置收藏**：在设置 → 服务商 → 编辑里，每个模型 ID 前加一个星标，点一下收藏或取消，随「保存」一起生效。服务商列表里收藏的模型带星标。
- **切换模型**：模型选择器按服务商分组；新对话、会话内切换和标题模型用的是同一个选择器。
  - 有收藏的服务商只列收藏的模型。当前会话正在用的模型即使没收藏也照常显示。
  - 没有收藏的服务商列出全部模型，和现在一样。
  - 隐藏了模型时，分组末尾显示「全部 N 个模型」，点开后本次展开，方便偶尔用一下其他模型。
- 设置备份包含收藏状态；备份格式只认当前结构，加字段之前导出的备份文件不能再导入。

## 契约

- **schema**：core 升到 29，`core_models` 加 `starred INTEGER NOT NULL DEFAULT 0 CHECK(starred IN (0, 1))`。转换脚本 `scripts/db/core-29.sql` 只加这一列，现有模型都默认为未收藏。
- **store**：模型的读写类型和备份条目加 `starred: bool`。
- **Gateway**：模型列表里的每个模型加 `starred`；创建、修改模型的请求体必带 `starred`。不新增接口。
- **Web**：ModelPicker 按上面的规则过滤；EndpointDialog 的模型行加星标。

## 验收

- **本地**：转换脚本测试；收尾检查。
- **human**：收藏几个模型后，看选择器是否只显示收藏的模型，以及「全部 N 个模型」能否展开。
